# 부정클릭 모니터링 메뉴얼

광고 클릭 중 의심되는 반복 방문(부정클릭)을 감지하고, 경고창 노출과 IP 차단까지 관리하는 **부정클릭 모니터링** 사용 방법을 안내합니다.

!!! note "문서 상태"
    이 문서는 초안(2026-10-01) 기준입니다. 화면과 기능은 변경될 수 있습니다.

## 메뉴 구성

| 메뉴 | 설명 |
|------|------|
| [모니터링 설정](setup.md) | 도메인 등록, 스크립트 삽입, 경고 팝업과 자동 차단 설정 |
| [모니터링](monitoring.md) | 의심 IP 목록 조회, 상세 확인, IP 차단 |
| [IP 차단 목록](ip-block.md) | 차단한 IP 확인 및 해제 |
| [경고창 예시](warning-examples.md) | 방문자에게 보이는 1단계/2단계 경고창 |
| [모니터링 항목](fields.md) | 목록에 표시되는 항목의 의미 |
| [유입경로 분석](traffic-analysis.md) | 기간별 유입 현황, 인기 검색어, 광고 잔여 예산 |

## 이용 순서

1. [모니터링 설정](setup.md)에서 도메인을 등록하고 스크립트를 웹사이트에 삽입합니다.
2. 같은 화면에서 경고 팝업과 자동 차단 조건을 설정하고 **설정 저장**을 누릅니다.
3. [모니터링](monitoring.md) 화면에서 의심 IP를 확인하고, 필요하면 차단합니다.

!!! info "지원 매체 안내"
    IP 차단 기능은 현재 **네이버 광고**만 지원합니다.
